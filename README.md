# My Life, My Story

## Cara menjalankan di VS Code
1. Buka folder ini di VS Code (File > Open Folder).
2. Pasang ekstensi **Live Server** (Ritwick Dey).
3. Klik kanan `index.html` > **Open with Live Server**.

Mengklik dua kali `index.html` juga bisa, tetapi Live Server lebih disarankan
(video dan visualizer musik berjalan paling baik di sana).

## Mengedit cerita
Buka `index.html`, cari komentar `EDIT`. Ganti teks di dalam tag `<p>...</p>`.
Ganti label `[ Tahun / periode ]` dengan tahun yang sesuai.

## Halaman lagu
`songs.html` berisi pemutar lagu (Freedom Dive dan Canon Rock). Daftar lagu dan catatannya ada di array `TRACKS` di dalam berkas itu (cari komentar `DAFTAR LAGU`).

## Berkas
